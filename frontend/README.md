# P-Patch frontend
React + Vite UI for Judkins Park P-Patch (dashboard, plots, tasks, inventory, admin).
## Prerequisites
- Node.js 20+ (18+ may work)
- npm (comes with Node)
- Backend running locally if you need API calls (Django on port 8000)
## Setup from scratch
From the repo root:
```bash
cd frontend
npm install
```

To run locally:
```bash
npd run dev
```
